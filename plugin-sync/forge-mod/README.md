# PlayerManagerSync Forge Mod

Este é um esqueleto inicial para uma versão Forge do PlayerManagerSync.

## Como construir

1. Instale o Gradle (ou use o wrapper, se disponível).
2. Execute `gradle build` a partir da pasta `forge-mod`.

## Plataforma alvo

- Forge 1.20.4
- Java 17 (recomendado para Forge 1.20.4)
